# فعال‌سازی کپی‌پیست بین سیستم خودت و VM — INFINITY Clipboard Add-on

این بسته **هیچ اختلالی در پروژه ایجاد نمی‌کند** و به همین دلیل ساخته شد:

- زنجیره‌ی تست کاملاً دست‌نخورده می‌مونه: همون فایل‌های OVMF، همون vars، همون فلش
  boot فقط‌خواندنی `usb-d`، همون memory.efi، همون سریال‌لاگ و همون پورت مانیتور.
- تنها تفاوت سخت‌افزاری: یک کنترل‌ر `virtio-serial` اضافه می‌شه — همون «لوله‌ای» که
  عاملِ کلیپ‌بوردِ داخل ویندوز (vdagent) از طریقش با QEMU حرف می‌زنه. این کنترل‌ر
- به سرویس‌های متغیر UEFI و به hookهای درایور **هیچ ربطی ندارد**.
- سریال‌لاگ `serial-phase-d.log` دقیقاً مثل قبل تولید می‌شه — از نظر مدرنک هیچ فرقی
  نمی‌کنه. ولی اگه خواستی یک ران صددرصدِ بکر داشته باشی، همیشه می‌تونی از
  `phase-d.bat` اصلی استفاده کنی — اون دست نمی‌خوره.

## نصب یک‌بارمصرف (دو طرف، یکی‌بار برای همیشه)

### داخل VM (ویندوز مجازی):
1. یک بار VM رو مثل همیشه با `phase-d-spice.bat` بوت کن (درایور مهمه، نه فایل بات).
2. `spice-guest-tools-latest.exe` رو نصب کن (همونی که داری).
3. ویندوزِ داخل VM یک‌بار ری‌استارت کن. سرویس vdagent از این به بعد خودکار بالا میاد.

### روی سیستم خودت:
1. **virt-viewer** برای ویندوز رو نصب کن — از `https://virt-manager.org/download`
   بخش Windows installer (فایل MSI-ی x64).
2. `spice-connect.bat` که کنار این راهنماست رو داشته باش.

## روش استفاده

1. به جای `phase-d.bat`، از این به بعد وقتی کلیپ‌بورد می‌خوای **`phase-d-spice.bat`** رو
   اجرا کن (با همون شماره‌ی حالت همیشه‌ات: 1 یا 2 یا 3).
2. پنجره‌ی QEMU مثل همیشه باز می‌شه و همه‌چیز مثل قبل کار می‌کنه (عکس گرفتن هم
   از همین پنجره هنوز ممکنه).
3. وقتی ویندوز بالا اومد، **`spice-connect.bat`** رو دابل‌کلیک کن → پنجره‌ی
   remote-viewer باز می‌شه که همون VM داخلشه، با کلیپ‌بورد دوطرفه.
4. **کپی از VM به سیستم خودت:** داخل پنجره‌ی remote-viewer متن رو با موس انتخاب کن →
   `Enter` بزن (یا Ctrl+C) → حالا روی سیستم خودت Paste کن.
5. **پیست از سیستم خودت به VM:** روی سیستم خودت کپی کن → داخل پنجره‌ی remote-viewer
   کلیک کن → راست‌کلیک یا Ctrl+V.

## نکته‌ها و رفع اشکال

- اگه Ctrl+V داخل پنجره‌ی آبی PowerShell کار نکرد: **راست‌کلیک** کن (پیش‌فرض کنسول) یا
  در Properties کنسول گزینه‌ی «Enable Ctrl key shortcuts» رو فعال کن و پنجره رو دوباره باز کن.
- اگه remote-viewer گفت connect نمی‌شه: یعنی VM با `phase-d-spice.bat` بالا نیست —
  `phase-d.bat` معمولی کانال کلیپ‌بورد رو باز نمی‌کنه.
- اگه phase-d-spice گفت QEMU تون SPICE ندارد: یعنی بیلد QEMU قدیمی/ناقصه — نصاب رسمی
  `https://qemu.weilnetz.de/w64/` را دارد. در این حالت همان phase-d.bat معمولی همه‌چیز را انجام می‌دهد.
- بدون هیچ نصب اضافه‌ای هم همیشه می‌تونی خروجی متن رو از VM بیرون بیاری: داخل VM روی
  فلشِ transfer ذخیره‌اش کن و `refresh-files.bat` بزن — فایل توی پوشه‌ی `transfer\` می‌شینه.
- بوت اول بعد از نصب spice-guest-tools ممکنه کمی کندتر باشه (نصب درایور) — طبیعیه.
